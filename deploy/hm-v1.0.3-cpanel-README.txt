Upload steps (cPanel File Manager)
----------------------------------
1. Upload hm-v1.0.3-cpanel.zip to your Laravel app root (same folder as artisan).
2. Extract the ZIP and overwrite existing files.
3. In server .env set: HM_APP_VERSION=1.0.3
4. Clear caches (Terminal or SSH):
   php artisan view:clear
   php artisan route:clear
   php artisan config:clear
5. Hard-refresh the browser (Ctrl+F5).
6. Confirm login page shows v1.0.3.
